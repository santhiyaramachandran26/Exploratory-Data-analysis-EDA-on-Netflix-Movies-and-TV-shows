## 📌 Project Overview

This project carries out an **Exploratory Data Analysis (EDA)** on the Netflix dataset to understand how the streaming giant's catalog has evolved over time.

### 🔍 Key Insights Covered:
* **Movies vs. TV Shows:** Breakdown of content distribution across formats.
* **Growth Over Time:** Analysis of content release years and annual addition rates.
* **Geographical Trends:** Identification of top content-producing countries.
